Local-first OSINT toolkit

PersonaShield helps you investigate targets without handing your data to third-party services.

PersonaShield is a privacy-conscious command-line framework for checking usernames, domains, email addresses, phone numbers, and breach data locally. It is designed for analysts who want transparent results and full control over their workflow.

View repository Install via pip

Command line ready

Run pip install personashield and use the built-in CLI to query local records and generate reports.

No API keys required

PersonaShield keeps the workflow local-first, so you can run it without signing up for external services.

Privacy-preserving reports

Generate HTML reports that summarize findings while keeping the analysis process transparent and portable.
